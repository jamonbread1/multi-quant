# 短周期趋势（1H 突破 + 短持仓）预登记检验 — 结论 v1.0

**脚本**: `s1_short_trend_v1_0.py`；引擎 `s1_engine_v1_3.py`
**报告**: `s1_short_trend_v1_0.md`；数据 `s1_short_trend_v1_0.csv`

## 1. 动机与范围
上一轮（F1–F3）的频率实验只是在 4H 上增加 S1 的信号，并没有测试真正的高频策略。
用户指出这一点，并选择了“短周期趋势（1H 突破 + 短持仓）”作为检验对象。本轮把同一套突破逻辑搬到 1H，检验更高频的版本能否在冻结成本下改善结果。

**不包括**：1H 均值回归（项目 S2 在 4H 上已失败，未重新测试）、多周期入场（未选择）。

## 2. 配置（预登记，共 5 个）
- F0：冻结版 4H don48（基准）
- H24 / H48 / H96：1H 唐奇安 24 / 48 / 96，出场为内通道 n//2
- H192：1H don192（4H don48 的 1H 等价窗口，对照）

其它参数与冻结版一致：ADX≥15、3×ATR 吊灯、止损封顶 9%、止损后需信号回零再入场。成本为冻结版口径（手续费 0.05% + 滑点 0.03% 每边 + 资金费，按 1H 折算），LEV 1.5。

## 4. 判定（预登记）
H24、H48、H96、H192 均**不满足**“全样本 CAGR > F0 且 Calmar ≥ F0 且 OOS CAGR ≥ F0”。
H192 满足 Calmar 与 OOS CAGR 两项，但全样本 CAGR 为 37.9%，低于 F0 的 38.9%，差约 1pp。

**结论：高频未改善。**

## 5. 解读

1. **高频的成本问题很清楚。** H24 每年约 179 笔，单笔均净收益为 −0.01%，成本是毛收益的 143%。这说明单笔优势不足以覆盖成本：1H 周期的突破信号，平均每笔赚的钱几乎都付给了手续费和滑点。这与第 6 节的成本估算一致。
2. **周期越短，结果越差。** 从 H24 到 H96，回撤和 CAGR 都随周期拉长而改善，频率越高越差。
3. **H192 值得注意，但不构成采纳依据。** 它是 4H 逻辑在 1H 上的等价版本，交易数与 F0 相近（30 笔/年 vs 28 笔/年）。它的盘中回撤从 −65% 降到 −47%，Calmar 从 0.60 升到 0.81，OOS 也更好；但 CAGR 略低于 F0。它的差异主要来自路径（入场与出场的时点不同），而不是频率的提高。这是一个事后观察，判定规则仍然是“未通过”；若要认真对待，需要另起版本、重新登记并做独立检验。

## 6. 成本估算（用于判断高频是否可行）
- 单笔成本（LEV 1.5）：手续费 0.05% + 滑点 0.03% 每边，双边合计 0.16% 名义，相当于约 0.24% 权益，另加资金费。绩效表记录的单笔成本为 0.291%。
- 因此，高频策略要成立，单笔毛优势必须稳定超过约 0.3%。突破策略的优势来自少数大趟，平均单笔优势远低于这一水平（H24 实测为负）。

## 7. 限制
- 只测了一个高频方向（1H 突破），未测 1H 均值回归。
- 1H 参数（24/48/96/192）为预登记的少量配置，未做扫描。
- OOS 只有约 2.8 年，且 H192 的改进是事后观察，需要独立验证。
