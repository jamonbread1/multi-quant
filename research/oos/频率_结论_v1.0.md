**成本（冻结口径）**: taker 0.05% + 滑点 0.03%（双边）+ 资金费 0.004%/8h；LEV 1.5；资金费开启。

## 回答：提高交易频率是否改善？

**否。** 频率越高，全样本与 IS 结果越差，只有 OOS 上 F2 微弱改善（Calmar 2.54→2.72，OOS 期末 133→144U），而 IS 与全样本都变差。
- **F1（止损后即可再入）** 笔数约 3 倍，胜率降到 35%，全样本 3.3U，几乎全部亏完。被止损后在同一段下跌/震荡里反复开仓，是把亏损放大。
- **F3（don24，更快入场）** 笔数 304，全样本 76U，MDD −87%，OOS 也明显差于 F0。与此前速度变体结论一致。
- **F2（ADX0，放宽过滤）** 增加 6 笔，全样本降到 252U，MDD 变深；OOS 的微弱改善不足以支持改动。它没有通过“全样本与 IS 都不差”的隐含要求，且属于事后选择的单一窗口。

结论：当前瓶颈不是“信号数量不足”，而是额外信号的质量低。“错过机会”的直觉在这组数据上不成立。

## Q2：定型版本（LEV 1.5）全区间结果与对账

| 指标 | 官方绩效表 (20261010) | 本引擎复现 F0 |
|---|---|---|
| 期末 U | 237.82 | 267.43 |
| 笔数 | 184 | 183 |
| CAGR | 36.2% | 38.5% |
| MDD | 68.8%（2022-08，按月） | −65.2%（盘中） |
| Calmar | 0.53 | 0.59 |
| 胜率 | 44.0% | 43.7% |

**对账结论（未完全对齐）**:
1. 起点敏感性很大：同一引擎、同一成本，播种起点 2019-12-25 / 2020-01-01 / 2020-01-08 分别得到 267 / 407 / 315U。只有 2019-12-25 能复现官方首笔（2020-01-28 @173.02）。因此官方口径必须用 2019-12-25 播种。
2. 按官方日志逐笔比较：183 笔的方向 100% 一致，开仓价 99.5% 一致，离场价多数只差零点几美元，逐笔收益平均绝对差 0.2%。
3. 剩余差距约 30U（11%）。官方日志 `qty×0.1×(离场−入场)` 的毛利合计为 341U，而绩效表毛利为 275.5U，两者本身也不一致。按冻结成本对日志逐笔收益重放只得到约 195U。**因此绩效表无法仅由日志完全复现，剩余差距尚未解释。** 不应宣称精确对账。
4. 绩效表的 MDD 68.8% 与本引擎盘中 MDD 65.2% 口径不同（前者按月/已实现，后者盘中），不能直接比较。
