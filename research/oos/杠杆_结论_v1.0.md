# 杠杆倍数对年化的影响 — 结论 v1.0

**脚本**: `leverage_v1_0.py`（引擎 `s1_engine_v1_1.py`）  **报告**: `leverage_report_v1_0.md`  **数据**: `leverage_summary_v1_0.csv`、`leverage_curve_v1_0.png`
**口径**: S1 海龟（don48 / ADX15 / 止损 min(3·ATR, 9%)），净口径（taker 0.05%/边 + 资金费，滑点 0），逐仓，强平维持保证金 0.5%，30U 起始。

## 2. 结论

1. **杠杆确实提高年化，但提高的主要是风险。** 1.0x → 2.0x，全样本年化 +31% → +50%，盘中回撤 −48% → −76%。Calmar（年化/回撤）在 1–2x 之间基本持平（约 0.65），说明在这个区间，杠杆基本是按比例放大收益和风险，并没有带来更好的风险收益比。
2. **超过约 2 倍后，收益边际递减，回撤急剧恶化。** 3x 的年化仍高于 2x，但回撤达 −91%；5x 年化反而降到 +24%（全样本），盘中回撤 −99%。原因：单笔最坏亏损约为 杠杆 × 止损幅度（9%），5x 时单笔可亏约 45% 的权益，连续几笔亏损后复利路径会被打穿，之后的收益很难恢复。
3. **10x 会被强平。** 强平距离 ≈ 1/10 − 0.5% = 9.5%，略大于止损上限 9%，但盘中触发强平时无法等到止损成交，于是被强平，全部权益归零。
4. **样本外更强，但不能外推。** OOS（2024 起）各杠杆年化都更高，说明这段行情更顺。但 OOS 只有约 2.8 年，且一笔强平或一段连续亏损的代价在任何杠杆下都会被放大。
5. **对“年化太慢”的直接回答。** 若只看年化，1x → 2x 能把全样本年化从约 31% 提到约 50%。但对应的盘中回撤从约 −48% 扩大到约 −76%。在 30U 本金规模下，−76% 的回撤意味着几乎无法承受，这与用户“收益要快”的目标是冲突的。**在 Calmar 不改善的前提下，单纯加杠杆不是可靠的提速手段。** 更有价值的方向是改善信号质量（方向 B 的结论显示状态滞后，短期内难以直接提升），而不是放大敞口。

## 3. 局限与未做

- **回撤口径**：主口径为盘中最差 MTM（用每根 bar 的 high/low 估计）。bar 内的真实顺序无法从 4H 数据确定，因此盘中回撤是近似值，且可能偏乐观或偏悲观。
- **保证金模式**：假设逐仓；全仓（cross）下强平条件不同，结果需要另行检验。
- **强平价格**：假设在触及强平价时按强平价成交，未考虑真实交易所的穿仓与滑点，实际强平损失可能更大。
- **未做网格寻优**：只跑了预登记的 6 个档位，档位之间的曲线是插值推断。
- **资金费与滑点**：资金费按 0.004%/8h 计，滑点设为 0（与 v1.0 默认一致）。高杠杆时滑点影响更大，这里偏乐观。
- **建议**：若未来需要杠杆，优先在 1.5x 附近小范围测试，并在全仓模式下重新验证强平距离。

## 4. 下一步建议（待用户决定）
- 不推荐在当前信号上把杠杆提到 2x 以上。
- 若要提速，应在信号层面（进场/状态）寻找改进，而不是提高杠杆。
