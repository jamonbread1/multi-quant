# 外部改良策略评审: "海龟趋势进化版 (Turtle Trend Pro, HA)" v1.0

**来源**: 用户上传，仓库 `origin/main` 提交 062568e，文件 `海龟趋势进化版_Turtle Trend Evolution (Copy).xml`（Pine Script v6）。
**性质**: 评审，不是检验。脚本未附任何回测结果。

## 1. 策略要点（代码实际行为）
| 项目 | 外部版本 | 我们冻结版 S1 |
|---|---|---|
| 入场 | Donchian 20（System 1，可切 55） | Donchian 48 |
| 出场 | 反向 Donchian 15（可切 20） | 反向 Donchian 24 |
| 突破价格 | Heikin Ashi 高低点（默认开启） | 普通 OHLC |
| 趋势过滤 | ADX(14) 经 EMA3 平滑，阈值 20 | ADX(14) 原始值，阈值 15 |
| 止损 | 收盘价 − 2×ATR(20)，每根 bar 重算 | 入场价 − 3×ATR，上限 9% |
| 冷却 | 任一入场后 5 根 bar 内不再入场 | 止损/强平后需方向回零才能再入 |
| 杠杆 | 无（10% 权益/笔） | 1.5x |
| 其他过滤 | 趋势 MA、RSI、成交量均默认关闭 | 无 |
| 成本 | 佣金 0.075%/边 + 2 tick 滑点 | 0.05% + 0.03%/边 + 资金费 |

## 2. 发现的问题
1. **没有绩效证据**。脚本注释和标题中没有任何 IS/OOS 结果，只有 2025 年的回测窗口设置。
2. **"入场价 − 2×ATR" 的说法与代码不符**。`strategy.exit` 的 stop 参数每根 bar 都用当前收盘价重算，实际是一个跟随收盘价的 2×ATR 止损，而不是锚定入场价的固定止损。它会随价格下移，不会上移锁定利润，也不会保持注释里的 "2x ATR from entry"。这是需要作者确认的逻辑差异。
3. **HA 突破改变了触发时机**。HA 最高价 = max(high, haOpen, haClose) 必然 ≥ 真实最高价，HA 最低价同理 ≤ 真实最低价。所以 HA 突破会比普通突破更早触发，假突破可能更多。脚本没有对比普通模式的结果。
4. **冷却只限制入场，不限制出场**。5 根 bar 的冷却不考虑止损后的状态，与我们的 "止损后需方向回零" 规则不同。
5. **信息面板、背景色、regime 分类**只影响显示，不影响交易。

## 3. 与我们已有结论的对应关系
- **入场更快 (20 vs 48)**：我们已测过更快入场。`don24` 全样本从 267U 降到 76U，MDD 从 −65% 恶化到 −87%（`freq_test_v1_0.csv`）。外部版本 20/15 的出场比例（0.75）与我们的 0.5 不同，**这个具体组合我们还没测过**。
- **2×ATR 止损**：我们之前的止损倍数存在悬崖效应（stop3 → stop4 收益掉 57%，见绩效表）。2×ATR 没有直接测过。
- **ADX 过滤**：我们已经用了 ADX 门控。EMA3 平滑的 ADX 与原始 ADX 的差别很小，不是新信息。
- **冷却期**：与我们的 "重入场" 测试（F1，止损后即可再入，全样本 3U）同方向，都是增加交易，结果变差。
- **HA 突破**：唯一真正的新元素，我们没有测过。但它只改变触发时间，不改变信号的经济含义。
- **成本**：外部版本的成本假设（0.075% 佣金 + 2 tick）与我们的 0.08%/边 接近，没有低估。

## 4. 结论：对我们帮助有限
- 外部版本的参数改动（20/15、2×ATR、ADX 平滑、冷却）大部分已经在我们的测试中覆盖过，或者是我们已知会降低结果的方向。
- 唯一新的元素是 **HA 突破**。它有一定的理论合理性，但预期收益很小，而且会引入额外的回测与实盘差异。
- 脚本本身的止损实现有问题，不能直接采用，也不建议把它当作 "已验证的改良" 引用。

## 5. 如果要进一步检验（可选，优先级低）
若想测 HA 突破，需要新建一个引擎版本（新文件，不改 v1.0 与 v1.3），预登记 2 个配置：
- H1: 20/15、2×ATR（锚定入场价）、ADX 原始 20、冷却 5，普通价格突破；
- H2: 同 H1，仅突破价改为 HA。
并与 S1 冻结版（同成本口径）对比，报告 IS/OOS、交易笔数、MDD 和随机方向对照。
